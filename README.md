# Mohan Ghee — Homepage Redesign Preview (v2)

A client-facing design preview for the Mohan Ghee homepage redesign. The aesthetic is "vintage Indian provisions" — pulled directly from the brand logo's DNA: vermillion red, royal blue, saffron, and tin-yellow cream.

This is a static HTML/CSS preview. Once approved, it will be implemented as a Shopify theme.

**Live preview:** see GitHub Pages URL above.

## Brand assets used

Real photography sourced from `mohanghee.in`:
- All product photos (7 SKUs from the live Shopify CDN)
- The Bilona village banner, 1947 jingles banner, Morhav banner, brand certifications wall
- Real brand avatars for testimonials

## Stack

- Pure HTML + CSS, no framework
- Google Fonts: Alfa Slab One (display), Lora (serif body), Oswald (condensed labels), Tiro Devanagari Hindi (Hindi accents)
- All images served locally from `/assets`
